# Wealth Capsule

Privacy-preserving Personal AI for understanding personal finances.

## Project Goal

Wealth Capsule keeps private financial data under the user's control while using NVIDIA Nemotron for reasoning and Tavily for current external research.

## Core Technologies

- NVIDIA Nemotron
- Nebius Token Factory / AI Cloud
- Tavily
- Python
- FastAPI
- SQLite
- Agent orchestration

## Privacy Principle

Raw private financial data should not be sent to external research services.
